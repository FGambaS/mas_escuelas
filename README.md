# Más Escuelas

Proyecto desarrollado como actividad académica de la clase de Formulación de Proyectos

## Descripción del proyecto

Proyecto de intervención para el desarrollo de infraestructura escolar en el municipio de Yacopi

### Beneficiarios potenciales

Niños, niñas y jóvenes del municipio y sectores cercanos
